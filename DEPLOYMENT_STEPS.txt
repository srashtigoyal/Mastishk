✅ PRE-DEPLOYMENT CHECK
═══════════════════════════════════════════════════════════════════════════════

Step 1: Test Build
──────────────────
cd mastishk
npm run build

✅ Should see: "Compiled successfully"
❌ If errors: rm -rf .next node_modules && npm install && npm run build


Step 2: Test Locally
────────────────────
npm run dev
Visit: http://localhost:3000

Test:
  ✓ Landing page loads
  ✓ Can click "Get Started"
  ✓ Can click "Sign In"
  ✓ Dark mode toggle works
  ✓ No console errors (F12)


🌐 DEPLOYMENT PROCESS
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: PUSH TO GITHUB (2 minutes)                                         │
└─────────────────────────────────────────────────────────────────────────────┘

1.1 Initialize Git
──────────────────
git init
git add .
git commit -m "Initial commit - Mastishk by Srashti Goyal"


1.2 Create GitHub Repository
─────────────────────────────
→ Go to: github.com
→ Click: "+" → "New repository"
→ Name: mastishk
→ Description: AI-Powered Quiz Platform
→ Public or Private: Your choice
→ Click: "Create repository"


1.3 Push Code
─────────────
git remote add origin https://github.com/YOUR_USERNAME/mastishk.git
git branch -M main
git push -u origin main

✅ Code is now on GitHub!


┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: DEPLOY ON VERCEL (3 minutes)                                       │
└─────────────────────────────────────────────────────────────────────────────┘

2.1 Create Vercel Account
─────────────────────────
→ Go to: vercel.com
→ Click: "Sign Up"
→ Choose: "Continue with GitHub"
→ Authorize Vercel


2.2 Import Project
──────────────────
→ Click: "Add New..." → "Project"
→ Find: "mastishk" repository
→ Click: "Import"


2.3 Configure (Auto-detected)
──────────────────────────────
Framework: Next.js ✓
Build Command: npm run build ✓
Output Directory: .next ✓

→ Click: "Deploy"


2.4 Wait for Deployment
───────────────────────
⏳ Building... (1-2 minutes)
⏳ Deploying...
✅ Success!


2.5 Get Your URL
────────────────
You'll get a URL like:
  https://mastishk.vercel.app
  or
  https://mastishk-xyz123.vercel.app

✅ YOUR SITE IS LIVE! 🎉

🎨 CUSTOM DOMAIN (Optional)
═══════════════════════════════════════════════════════════════════════════════

Add Your Domain
───────────────
1. Buy domain (Namecheap, GoDaddy, etc.)
2. Go to Vercel → Project Settings → Domains
3. Click "Add"
4. Enter your domain: mastishk.com
5. Follow DNS instructions
6. Wait 5-60 minutes for DNS propagation
7. ✅ Your site is at your custom domain!

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Build Fails
───────────
→ Check build logs on Vercel
→ Run locally: npm run build
→ Fix errors shown
→ Push again: git push


Page Not Found
──────────────
→ Check app/(auth)/layout.js exists
→ Verify folder structure
→ Check Vercel logs


Site Not Loading
────────────────
→ Wait 2-3 minutes after deployment
→ Clear browser cache
→ Try incognito mode
→ Check Vercel status page


Dark Mode Not Working
─────────────────────
→ localStorage works on deployed sites
→ Clear browser cache
→ Check browser console for errors
