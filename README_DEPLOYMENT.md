## ⚡ Super Quick Deploy (2 Minutes)

```bash

npm run build

# 2. Push to GitHub
git init
git add .
git commit -m "Initial commit - Mastishk by Srashti Goyal"
git remote add origin https://github.com/YOUR_USERNAME/mastishk.git
git push -u origin main

# 3. Deploy on Vercel
# Go to vercel.com → Import repository → Deploy
```

## 🆘 Common Issues & Solutions

### **Build Fails:**
```bash
rm -rf .next node_modules package-lock.json
npm install
npm run build
```

### **Page Not Found:**
- Check `app/(auth)/layout.js` exists
- Verify folder structure

### **GitHub Push Fails:**
- Make sure repository exists on GitHub
- Check remote: `git remote -v`

### **Vercel Deploy Fails:**
- Check build logs
- Verify `package.json` is correct
- Ensure `next.config.js` exists
