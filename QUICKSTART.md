# ⚡ Mastishk - Frontend Only Quick Start

Get Mastishk running in 2 minutes! No backend, no database, no API keys needed!

## 🎯 Prerequisites

- Node.js 18+ installed ([Download](https://nodejs.org/))

That's it! No MongoDB, no API keys, nothing else needed! 🎉

## 🚀 Steps

### 1. Install Dependencies (1 min)

```bash
cd mastishk
npm install
```

### 2. Start Development Server (30 seconds)

```bash
npm run dev
```

### 3. Open Application (10 seconds)

Visit: **http://localhost:3000**

## ✅ Test It

1. Click "Get Started Free"
2. Create account (stored in browser)
3. Generate a quiz on any topic
4. Take the quiz!
5. View your dashboard

## 🎉 Done!

You're ready to use Mastishk!

---

## 📚 What's Different (Frontend Only)

- ✅ **No Backend** - Everything runs in browser
- ✅ **No Database** - Uses localStorage
- ✅ **No API Keys** - Mock data and templates
- ✅ **Instant Setup** - Just npm install and run
- ✅ **Easy Deploy** - Deploy to Vercel in 1 click

## 🚀 Deploy to Vercel

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel

# That's it!
```

## 🆘 Issues?

### Port in Use
```bash
# Use different port
npm run dev -- -p 3001
```

### Module Error
```bash
rm -rf node_modules package-lock.json
npm install
```
