⚡ QUICK START COMMANDS
═══════════════════════════════════════════════════════════════════════════════

1. Install Dependencies
   ────────────────────
   npm install

2. Setup Environment
   ─────────────────
   cp .env.example .env
   # Then edit .env with your credentials

3. Start Backend (Terminal 1)
   ──────────────────────────
   npm run server:dev

4. Start Frontend (Terminal 2)
   ───────────────────────────
   npm run dev

5. Open Browser
   ────────────
   http://localhost:3000


📋 PREREQUISITES
═══════════════════════════════════════════════════════════════════════════════

Required:
  ✓ Node.js 18+ (https://nodejs.org/)
  ✓ MongoDB (local or Atlas: https://www.mongodb.com/cloud/atlas)
  ✓ Groq API Key (https://console.groq.com)

Optional (for deployment):
  ⭐ Vercel Account (https://vercel.com)
  ⭐ Render Account (https://render.com)


🎯 WHAT YOU GET
═══════════════════════════════════════════════════════════════════════════════

✨ Features:
  • AI-powered quiz generation on any topic
  • Multiple question types (MCQ, True/False, Fill-in-blank, Short answer)
  • Upload PDFs/text files to generate custom quizzes
  • Real-time performance analytics and insights
  • Global leaderboards and daily challenges
  • Streak tracking and achievement system
  • Dark/light mode with premium UI
  • Admin dashboard for user management

🛠️ Tech Stack:
  Frontend: Next.js 14, React 18, Tailwind CSS, Framer Motion
  Backend: Node.js, Express.js, MongoDB, Mongoose
  AI: Groq API for quiz generation
  Auth: JWT with bcrypt password hashing
  State: Zustand for state management

🔧 COMMON TASKS
═══════════════════════════════════════════════════════════════════════════════

Create Admin User:
  node server/utils/seedAdmin.js

Generate JWT Secret:
  node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

Test API Health:
  curl http://localhost:5000/health

Reset Database:
  # In MongoDB shell
  use mastishk
  db.dropDatabase()


🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

MongoDB Connection Error:
  → Check MONGODB_URI in .env
  → Ensure MongoDB is running (local)
  → Verify IP whitelist (Atlas)

Groq API Error:
  → Verify GROQ_API_KEY is correct
  → Check API credits/quota
  → Try different model

Port Already in Use:
  → Change PORT in .env
  → Kill process using port

Module Not Found:
  → rm -rf node_modules package-lock.json
  → npm install
